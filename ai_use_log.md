## Purpose of AI Assistance
  ChatGPT was used as a supporting tool during the PulseCart case study for understanding assignment requirements, clarifying code and concepts, debugging errors.

## What I Asked AI For
1. Help with Python and pandas syntax for data cleaning and transformation.
2. Guidance on statistical calculations and hypothesis testing.
3. Guidance on building leak-free churn features and supervised models.
4. Help with model evaluation and error analysis.
5. Guidance on clustering implementation and evaluation.
6. Help with time-series analysis and forecasting.
7. Help with regex pattern construction.
8. Help with ANN implementation and confusion-matrix analysis.
9. Help in project explanations.

## What I Kept
- Hypothesis testing and p-value interpretation for comparing churn and return rates.
- Leak-free feature engineering and Random Forest evaluation using precision, recall, ROC-AUC, and error analysis.
- K-Means/DBSCAN implementation and evaluation for customer segmentation.
- Time-series analysis using a time-based split and naive forecasting.
- Regex pattern construction for extracting order IDs, emails, and phone numbers.
- ANN image classification including image preprocessing, model implementation, and confusion-matrix analysis.
- Relevant Python syntax, debugging suggestions.

## What I Did Not Keep
- Unused alternative modeling approaches.
- Extra visualizations that were not required.
- Suggestions not relevant to the PulseCart dataset.
- Assumptions or interpretations not supported by the analysis.
