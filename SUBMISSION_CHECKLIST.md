# Submission checklist

Copy this into the repo as `SUBMISSION_CHECKLIST.md` and tick it before freeze.

- [ ] `README.md` answers the five business questions with numbers
- [ ] `README.md` says exactly how to rerun
- [ ] `queries.sql` contains the six required statements
- [ ] `analysis.ipynb` or `main.py` runs top to bottom
- [ ] `requirements.txt` is present
- [ ] `ai_use_log.md` is present (write `None` if unused)
- [ ] At least four meaningful Git commits
- [ ] No `last_active_date` used as a raw churn feature
- [ ] Train/test split does not shuffle a time series
- [ ] Repo URL sent to the training lead before the deadline
