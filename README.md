# PulseCart Live Case — start here

This folder is what you give the trainees.

1. Open `PulseCart_Live_Case_Brief.docx` and read it end to end before touching the data.
2. Load `data/mysql/pulsecart_dump.sql` in MySQL Workbench (`File → Run SQL Script`). Database name: `pulsecart`.
3. If Workbench is unavailable, use the CSVs in `data/csv/`. You still have to write `queries.sql`.
4. Shipment photos live in `data/images/` with labels in `data/csv/image_labels.csv`.
5. Submit one GitHub repo. Deliverables are listed in the brief.

Allowed libraries: Python 3.10+, pandas, NumPy, scikit-learn, seaborn, matplotlib, plus Keras/TensorFlow or PyTorch for Station H. MySQL Workbench for Station A.
